# KeyCabinet

Веб-приложение учёта выдачи ключей офисных кабинетов.

**Студент:** Шамиль Зарипов  
**Дисциплина:** Методы искусственного интеллекта · ДЗ4  
**Стек:** React 19, Vite, TypeScript, Tailwind CSS v4, Vitest

## Функции MVP

1. Список ключей со статусами (свободен / выдан / просрочен)
2. Выдача ключа сотруднику по ФИО
3. Возврат ключа и фильтр/поиск по кабинету, названию, сотруднику

## Rider (рекомендуется)

Проект открыт как `~/RiderProjects/KeyCabinet` (этот каталог — корень Vite-приложения).

1. Вверху выберите Run Configuration **npm: dev**
2. Нажмите **Run ▶** (или Shift+F10)
3. Откройте адрес из консоли Run (обычно `http://localhost:5173`)

Также есть конфигурация **npm: test**.

Копия для сдачи лежит в `~/Desktop/МИИ Зарипов/4/submission/` — перед загрузкой на платформу синхронизируйте отсюда при необходимости.

## Запуск из терминала

```bash
npm install
npm run dev
```

Откройте адрес из терминала (обычно `http://localhost:5173`).
