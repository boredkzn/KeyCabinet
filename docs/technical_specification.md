# ТЗ — KeyCabinet (ДЗ4, Шаг 1)

> Перенесено в `docs/`. Актуальный обзор проекта: [README.md](../README.md).

**Студент:** Шамиль Зарипов  
**Стек:** React + Vite + TypeScript + Tailwind CSS  
**UI-библиотека:** Tailwind CSS (utility-классы, без MUI)

## Цель

Фронтенд-приложение для ресепшена офиса: видеть, какие ключи кабинетов свободны, кому выданы и какие просрочены.

## Целевая аудитория

Сотрудник ресепшена / администратор офиса.

## Функциональные требования (минимум 3)

1. **Каталог ключей** — карточки с комнатой, этажом, статусом и держателем.
2. **Выдача** — для свободного ключа ввод ФИО и подтверждение; состояние loading → success/error.
3. **Возврат и фильтр** — принять ключ обратно; поиск и фильтр по статусу.

## Нефункциональные

- Адаптив: 1 колонка на телефоне, 2 на md+.
- Mock-данные без API.
- Автотесты Vitest (логика + UI).
- Русский интерфейс.

## Вне скоупа ДЗ4

Авторизация, история аудита на сервере, печать бейджей.
