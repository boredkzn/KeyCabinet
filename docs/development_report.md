## 1. Процесс разработки

Работа шла по шагам задания: ТЗ → инициализация Vite/React/TS → компоненты → состояния → тесты → адаптив → рефакторинг.

Стек выбран под шаги курса (Vite, Tailwind, package.json). Тема KeyCabinet — учёт ключей офиса; не пересекается с ParcelHub / StudyNotes / TodoCli.

## 2. Техники работы с AI

- Генерация каркаса: «создай Vite React-TS проект с Tailwind v4 и Vitest».
- RTCF-промпты для компонентов: роль Senior Frontend, задача — KeyCard с выдачей/возвратом, контекст mockKeys, формат — TypeScript без any.
- Отладка: описание симптомов («кнопка Выдать не блокируется при loading») → точечный патч.
- Рефакторинг: вынести issueKey/returnKey/filterKeys в utils для тестируемости.

## 3. Примеры промптов (кратко)

1. «Собери mock из 5 ключей: available/issued/overdue, русские подписи статусов.»
2. «Напиши Vitest-тесты: выдача, фильтр available, рендер App.»
3. «Сделай toolbar mobile-first: поиск на всю ширину, статусы переносом.»

## 4. Проблемы и решения

| Проблема | Решение с AI |
|---|---|
| Дубли DOM в тестах между кейсами | afterEach(cleanup) в setup.ts |
| Пустое ФИО при выдаче | Валидация в issueKey + role=alert на карточке |
| Перегруженный App.tsx | Вынести бизнес-логику в utils |

## 5. Адаптив

Проверено на ширинах ~375 / 768 / 1280: одна колонка карточек на телефоне, две на планшете/десктопе; тулбар складывается вертикально.
